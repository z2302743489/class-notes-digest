# 课堂纪要拆解 · class-notes-digest

把课堂**录音转写稿**或**群聊记录**，一键整理成可复习的结构化纪要。  
支持「标准纪要」与「考试复习版」双模式。

🌐 产品介绍页：https://z2302743489.github.io/class-notes-digest/ （启用 Pages 后生效）

本地预览：[docs/index.html](./docs/index.html)

## 解决什么问题

上课录音很长、群聊很乱，复习时找不到重点。  
本 Skill 帮你：**抓关键信息 → 归纳知识点 → 列出作业与待办 → 给出自测题**，且不编造原文没有的内容。

## 功能一览

| 能力 | 说明 |
|------|------|
| 多源输入 | 录音稿、微信/QQ 课堂群、自己的速记 |
| 标准纪要 | 一句话总结、知识点、强调点、作业、待办、疑问、复习提示 |
| 考试复习版 | 考点雷达、必背清单、易混对比、自测卷 |
| 忠于原文 | 不确定标「原文未明确」，不瞎编截止日或考点占比 |
| 可调详细度 | 简 / 标准 / 细 |

## 谁适合用

- 大学生整理网课 / 录播 / 课堂群
- 需要从聊天记录里捞作业和 DDL
- 考前想把一节课压成「能背、能测」的一页纸

## 怎么用

1. 把本仓库中的 `SKILL.md` 装到支持 Skill 的 Agent（按平台说明放入 skills 目录）。
2. 对 Agent 说：例如「用课堂纪要拆解，考试复习版」。
3. 粘贴转写稿或群聊导出全文。
4. 可选补充：课程名、日期、详细程度。

### 触发示例

```
把下面这节课整理成课堂纪要（标准）
——粘贴转写——

帮我弄考试复习版，课程：操作系统，第 5 周
——粘贴群聊——
```

## 输出长什么样

- **标准**：主题 → 知识点 → 强调/易错 → 例题作业 → 待办 → 疑问 → 自测  
- **考试复习**：考点雷达 → 必背 → 易混对比 → 题型 → 作业 → 自测卷 → 存疑  

完整字段与规则见 [`SKILL.md`](./SKILL.md)。  
样例见 [`examples/`](./examples/)。

## 设计原则

1. **可回查**：知识点可带原文短引/锚点  
2. **可行动**：作业与待办单独成块  
3. **可应试**：复习版强调对比、必背与自测  
4. **可信**：禁止幻觉式「老师说期末占 xx%」

## 局限

- 不替代听课；转写质量差时疑问区会变长  
- 不自动调用语音转写 API（请先自行转成文字再贴入）  
- 「考点频率」仅在原文有暗示或强调次数可依据时标注，否则会标明为推测
