## 2. 必背清单
- 进程：资源分配的基本单位  
- 线程：CPU 调度的基本单位  
- 同进程多线程：共享地址空间；各有自己的栈；全局变量彼此可见  

## 3. 易混对比

| | 进程 | 线程 |
|--|------|------|
| 基本单位 | 资源分配 | CPU 调度 |
| 地址空间 | 独立 | 同进程内共享 |
| 切换开销 | 通常更大（涉及地址空间/页表等） | 通常更小 |
| 全局变量 | 进程间默认不可见 | 同进程线程间可见 |
