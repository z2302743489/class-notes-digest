为什么用它

专为「课后整理」和「考前压缩」设计，而不是又一篇空泛摘要。

🎯

抓关键，不灌水

自动忽略约饭表情包，留下知识点、强调点、作业与 DDL。

📚

双模式输出

平时用标准纪要；考前切到考试复习版：必背、对比表、自测卷。

✅

忠于原文

没有的信息写「原文未明确」，禁止幻觉式考点占比或假答案。

四步上手

把 Skill 装进 Agent 后，粘贴文本即可。

STEP 01

安装 Skill

将仓库里的 SKILL.md 放入平台的 skills 目录。

STEP 02

准备原文

录音先转成文字，或导出课堂群聊记录。

STEP 03

一句话触发

「整理成课堂纪要」或「考试复习版」+ 粘贴全文。

STEP 04

拿到纪要

结构化 Markdown：可背、可查、可行动。

示例口令： 「用课堂纪要拆解，考试复习版。课程：操作系统，第 5 周。」然后粘贴转写稿。

两种输出模式

同一套原则，不同权重——平时记全，考前压薄。

标准纪要 默认

  1. 一句话总结 + 基本信息
  2. 关键知识点（可带原文锚点）
  3. 老师强调 / 易错点
  4. 例题、作业与阅读
  5. 待办 · 疑问 · 复习提示

考试复习版 考前

  1. 考试雷达（高/中/了解）
  2. 必背清单 + 易混对比表
  3. 题型提示与作业置顶
  4. 自测卷（附参考要点）
  5. 仍存疑点
